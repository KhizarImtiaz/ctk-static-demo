Auto Liability — High-Level Architecture

Read top-down: users → apps → access/session → services → data. The AI reads only through the API; everything joins on ToolkitID.
Application Access / session Service / API Data store External service Legacy / direct write
Multi-tenant: one shared central DB resolves each customer's own Claim DB replica. Apps and the AI never touch the DB directly — all reads/writes go through the .NET APIs (per-tenant, JWT). Legacy ASP is the exception (direct SQL) and is being retired.
